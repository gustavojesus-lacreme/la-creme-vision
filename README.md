# La Creme Vision

Crie a estrutura visual inicial responsiva para o sistema web da barbearia LA CREME BARBER.

Identidade visual:
- Azul-petróleo como cor principal
- Cinza muito claro quase branco nos fundos
- Dourado para detalhes premium
- Preto suave para contrastes
- Estilo: moderno, elegante, masculino, clean, profissional, futurista e simples de usar

Estrutura da página inicial pública:
- Cabeçalho com o nome LA CREME BARBER, menu de navegação (Início, Serviços, Barbeiros, Agendar, Entrar) e botão principal "Agendar horário"
- Hero principal com a frase em destaque "Acredita que acontece" e chamada para ação
- Seção de apresentação da barbearia
- Seção de serviços com cards estilizados
- Seção de barbeiros
- Seção de horários de funcionamento
- Seção de endereço e informações de contato
- Rodapé com a frase "Só alegria"

Foque estritamente na interface e experiência visual responsiva (mobile, tablet e desktop), sem banco de dados, login real, pagamentos ou WhatsApp por enquanto.
